#  Telecom Customer Churn Analysis

An end-to-end data analytics project to analyze customer churn in a telecom company. The project identifies the main factors affecting churn and provides business insights and recommendations to improve customer retention.

##  Repository Contents

- **Churn Analysis.ipynb**
  - Data cleaning
  - Data preprocessing
  - Exploratory Data Analysis (EDA)
  - Business insights

- **Churn Analysis.pbix**
  - Interactive Power BI dashboard
  - KPI cards
  - Customer segmentation
  - Churn analysis

- **Customer-Churn.csv**
  - Telecom customer dataset used for analysis.

- **EDA Report of Churn Analysis.pptx**
  - Presentation summarizing the analysis, key findings, and business recommendations

##  Key Insights

- Senior citizens are more likely to churn.
- Customers with month-to-month contracts have the highest churn rate.
- Customers paying through Electronic Check are more likely to churn.
- Higher monthly charges are associated with higher churn.
- Monthly Charges and Total Charges are positively correlated.
